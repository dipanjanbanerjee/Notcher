Steadier taskbar meter, more reliable file drops, and a few quality-of-life fixes.

### Fixes

- **Taskbar speed meter stays put.** Clicking the taskbar no longer hides it, and it no longer blinks on and off by itself.
- **The meter hides with the taskbar.** During a full-screen YouTube video or game, or when the taskbar auto-hides, the meter goes away too and comes back with the taskbar.
- **Dragging files onto the island works on every PC.** Notcher now keeps its own drop handler on all of the island's windows, including ones the web view creates later. If Notcher was started as administrator (which Windows blocks drops into), it restarts itself normally. Each drag is written to the log for troubleshooting.
- **Notcher Drop starts only when you ask.** Press Start in the Drop tab, or drag files onto the island. Opening the tab no longer starts it. It still stops after 10 idle minutes.
- **No surprise opening while you drag.** Holding a mouse button (moving a window, rearranging Home widgets, selecting text) no longer opens or closes the island. Dragging files onto it still opens Notcher Drop.
- **Weather names your place.** "Use my location" now shows your city or area instead of "Your location", and remembers it.

### New

- **Water reminder chime.** A short chime plays with the reminder. Turn it off in Settings › Wellbeing › Play sound with water reminder.
