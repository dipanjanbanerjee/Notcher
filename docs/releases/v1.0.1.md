Lighter, sharper, and it now updates itself.

### What's new

- **Much lower CPU use.** The island no longer redraws itself 60 times a second while it rests. The music bars, beat glow and hidden tabs were the cause.
- **Convert and Weather are separate tabs.** Convert shows handy amounts underneath. Weather adds the next 24 hours, the whole week, rain chance, and sunrise and sunset.
- **Accurate weather location.** Automatic mode uses Windows location, so turn on *Let desktop apps access your location*. You can also search for a city, an area or a **PIN code**.
- **Automatic updates.** Notcher checks for a new version when it starts and installs it by itself. You can also update, or turn this off, in Settings › Updates.

### Fixes

- Unit lists no longer show blank items until you hover them.
- The island stays open while you type a place or a note.
- Desktop and Start menu shortcuts show the new logo.
- "Today" on the taskbar speed meter is centred.
- The resting date and time glow softly, so they stand out from the black.

Installing 1.0.1 by hand is needed once. From then on, updates arrive by themselves.
