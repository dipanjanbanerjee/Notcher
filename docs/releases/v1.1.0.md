File drops that work on every PC, a calm taskbar meter, a cleaner clock, and precise weather.

### Fixes

- **Dragging files onto the notch works on every PC.** On some PCs the island's web view belongs to a separate WebView2 process that turns files from Explorer away, so drops were lost. Now, while you drag something toward the top of the screen, Notcher lays a small invisible drop catcher of its own over the notch (and over the open panel). Windows hands the files straight to Notcher, whatever the WebView2 version, display scaling or monitor. It goes away the moment you let go, so it never gets in the way of clicks. Every drag is logged (`file drop:` lines: drag-enter, drag-over, drop, and the reason when a drop fails).
- **The taskbar speed meter no longer blinks when you click the taskbar.** The meter is now attached to the taskbar itself, so Windows keeps it right above the taskbar. Before, clicking the taskbar raised the taskbar over the meter until Notcher noticed and pushed it back, and Start, Search or Task View briefly counted as "full screen".
- **The meter hides with the taskbar.** It goes away during full-screen YouTube and other full-screen browser videos, games and presentations, and when the taskbar auto-hides, and comes back with the taskbar. It reacts to Windows events instead of checking several times a second, and logs each show or hide with the reason (`taskbar meter:` lines).

### Changes

- **Simpler clock.** The date and time on the resting island use the Ubuntu typeface (bundled with the app) with no glow or shadow, in all four themes. The island's Glow feature is unchanged.
- **Precise weather location.** "Use my location" asks Windows for a high-accuracy position (GPS or Wi-Fi) and shows the place it found. If Windows location is off for desktop apps, Weather falls back to a guess from your internet connection and explains how to turn it on, with a button that opens the right Settings page.
- **Cleaner updates.** Updates replace the installed copy in the same folder and keep your shortcuts as they are. A copy installed from the .msi is now updated with the .msi, so it is never installed twice. Downloaded installers are deleted once used, and ones left behind by older versions are cleaned up.

### Your data is safe

Updating never touches your settings, clipboard history, notes, screen time or Notcher Drop files. Uninstalling keeps them too, unless you tick "Delete the application data" (off by default). Files in `Downloads\Notcher Drop` are always kept.
